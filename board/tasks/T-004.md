# T-004 · Watch every gate fail once

- Owner: @Q1
- Reviewer: @A1
- Milestone: M0
- Release condition it advances: M0 — the exit condition names this task directly. A gate
  nobody has watched fail is a gate nobody knows works.

## 1. Goal

Every negative test in `docs/_studio/docs/04-grokbot/setup.md` step 9 has been run once
against this repository, and its output is on record. Any gate that did not reject what it is
supposed to reject is fixed upstream before the first real task is dispatched.

## 2. Inputs

- `docs/_studio/docs/04-grokbot/setup.md` step 9 — the table of negative tests and the
  expected verdict for each
- `docs/_studio/docs/03-gates/gates.md` — what each gate claims to do
- `board/andon.md` — A-2026-08-21-1, the last time an unwatched gate cost a day

## 3. Lane

```
evidence/T-004/**
board/trust-ledger.md
```

## 4. Contracts

None. This task changes no behaviour; it establishes whether the behaviour already claimed is
real.

## 5. Definition of done

- [ ] Every row of the step 9 table has been attempted once, against a scratch branch of this
      repository, and its output kept.
- [ ] Each result is either the expected verdict, or a defect filed upstream in
      `sunset-studio` with the output attached. There is no third outcome, and "close enough"
      is not one of them.
- [ ] A gate that passed something it should have rejected is an andon pull, not a note. It
      means every merge that gate has approved is unverified.

## 6. Acceptance command

```bash
node docs/_studio/tools/gates/gates.test.mjs
node docs/_studio/tools/gates/selfcheck.mjs
node docs/_studio/tools/gates/spec-check.mjs
```

<!--
The acceptance command proves the gate engine still works after the exercise. The exercise

not something a script here can produce. The evidence is the record.
-->

## 7. Evidence

`evidence/T-004/` — command.txt, output.txt, diff-stat.txt, env.txt.

Plus one file per negative test, named for the row, each holding the branch, what was
attempted, and the gate output. A summary table with no outputs behind it is the thing this
task exists to stop being acceptable.

## 8. Timeout and escalation

- Expected: two sessions
- If blocked: escalate to @human, not to @Q1, who owns this card. The gatekeeper cannot be the
  only reader of the evidence that the gates work.
- Three failed attempts: stop and write `board/blockers/T-004.md`. There is no fourth.
