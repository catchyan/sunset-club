This repository holds only what belongs to this game. Everything about *how the team works*
lives in `sunset-studio` and arrives here as a verified read-only mirror. Every document is
in English, and every rule in it is one a gate actually enforces.

## 4. Contracts

New cross-repository contract: this repository consumes the framework at the version pinned
in `.studio-version`, mirrored byte for byte at `docs/_studio/`, verified by G1 on every
pull request. The mirror is never edited in place.

Being the first consumer of that contract is what proved it. Mounting the framework failed
G1 immediately — the mount wrote a file into the mirror after computing the manifest, so it
existed on disk and in no hash — and the framework's own gates could not have caught it,
because the framework repository has no mirror to mount. Fixed upstream and released as a
patch; this repository pins the patch. Two further defects surfaced the same way: the mirror
gate was never shipped, so a project was expected to hand-write it, and the mirror's
line-ending exemption was silently cancelled by a rule added below it.
