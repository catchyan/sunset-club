# T-003 · The workspace, and the eight steps it switches on

- Owner: @A1
- Reviewer: @Q1
- Milestone: M0
- Release condition it advances: M0. Nothing else in this repository can be built until a
  workspace exists; every M1 card is blocked behind this one.

## 1. Goal

`pnpm install && pnpm typecheck && pnpm lint && pnpm test` succeeds on a clean checkout, and
the eight CI steps that were dormant while there was no workspace are running.

## 2. Inputs

- `docs/02-tech/architecture.md` §2 — the package layout, the dependency direction, and §2.2,
  the table of scripts the gates run
- `.github/workflows/gates.yml` — the `build` and `feel` jobs, and what they check
- `docs/03-process/ownership.md` — `packages/**` falls back to A1, so a new package is an
  architecture decision before it is code

## 4. Contracts

`packages/protocol` is created **empty of message definitions**. `combat-events.md` is DRAFT
and says in its first paragraph that nobody may write combat presentation code until it is
frozen. Creating the package is not writing the contract.

## 5. Definition of done

- [ ] `pnpm-workspace.yaml` exists, with the eight packages named in architecture §2.
- [ ] The root `package.json` has all nine scripts from architecture §2.2. A stub that exits
      zero is acceptable on the first day; an absent script fails the build job, and the
      commit that creates the workspace turns all eight steps on at once.
- [ ] TypeScript strict, no exceptions, and `tsc --noEmit` clean across the workspace.
- [ ] `pnpm gates:deps` fails when `packages/sim` imports `three`, the DOM, the network or the
      filesystem. Prove it fails, then prove it passes — a dependency check nobody has watched
      reject anything is not known to work.
- [ ] `pnpm-lock.yaml` is committed. It is owned by `ANYONE` precisely so that whoever adds a
      dependency regenerates it; it is never edited by hand.
- [ ] No display string and no literal number in any source file. Both are CI-checked, and
      both are easier to get right on day one than to remove later.

## 6. Acceptance command

```bash
pnpm install --frozen-lockfile
pnpm typecheck
pnpm lint
pnpm test
pnpm gates:deps
```

in `packages/sim`, showing it rejected. Delete the import afterwards; keep the output.
