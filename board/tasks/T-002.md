# T-002 · Everything the first agent will read, made true

- Owner: @A1
- Reviewer: @Q1
- Milestone: M0
- Release condition it advances: M0 — "a deliberately boring pull request goes from dispatch
  to merge with no human touching it". A readiness audit found four documents that would send
  the first agent somewhere that does not exist or is no longer true.

## 1. Goal

An agent that reads this repository's documents and does what they say gets the result the
document promised. Nothing it reads on day one is stale, duplicated, or contradicted
elsewhere.

## 2. Inputs

- `sunset-studio` v3.1.0 — installs launchers so `node tools/lock.mjs` works here
- `docs/02-tech/infra.md` — states the branch protection settings that were the cause of
  andon A-2026-08-21-1, as though they were still correct
- `docs/04-plan/roadmap.md` — M0 exit condition counts the negative tests, and the count is
  wrong
- `docs/03-process/ownership.md` — the fun-audit directory that `feel-spec.md` §8 tells D1 to
  write into is covered by no glob, so the first file written there is out of lane by
  construction
- `board/backlog.md` — says it answers "what next" and lists what is finished
- `AGENTS.md`, `README.md`, `docs/README.md`, `board/README.md` — print the long form of
  commands that now work in the short form the SOPs use

## 5. Definition of done

- [ ] `.studio-version` reads `v3.1.0` and the mirror verifies against the upstream tag.
- [ ] `node tools/lock.mjs list`, `node tools/board/status.mjs`, `node tools/board/stall.mjs`
      and `node tools/verify-protection.mjs` all run here.
- [ ] Every document in this repository prints one form of those commands, the same form the
      SOPs print.
- [ ] `infra.md` states no branch protection setting of its own. There is one authority for
      what protection must be, and one tool that reads what it is.
- [ ] `roadmap.md` names no count of negative tests. The list is in `setup.md`; a number
      repeated here is a number that goes stale, and it already had.
- [ ] The ownership table covers the fun-audit directory, and that directory exists.
- [ ] `backlog.md` contains only unfinished tasks.
- [ ] `node docs/_studio/tools/gates/selfcheck.mjs` finds no reference to a path that does
      not exist.
