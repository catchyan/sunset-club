## Three things this table gets asked about

**Why `packages/content/**` has a fallback row.** Content grows subdirectories faster than
anyone updates a table, and without a fallback each new one is "unowned" and blocks an
honest pull request. The specific rows above still win, because the longest glob wins.

**Why the lockfile is `ANYONE`.** It has no author. It is regenerated by whichever role adds
a dependency, and giving it one owner means every dependency change in the repository needs
that role's pull request or an override. The first scaffold commit would have been blocked by
a file nobody writes.

**Why the mirror is `FRAMEWORK` and not `HUMAN`.** It was `HUMAN` once, which blocked the
only legal way to change it — upgrading the pinned version — leaving an administrator
force-push as the sole route. A rule that must be bypassed to get anything done teaches that
rules are optional, and that lesson does not stay confined to the one rule.

**Why there is no `CODEOWNERS` file.** There was one, hand-copied from this table, and by the
time anyone read it again it named a role that no longer existed and four paths that no longer
existed. It could never have enforced anything either: every bot pushes through one shared
GitHub account, and the owners here are role codes, not GitHub users, so GitHub resolves none
of them. The lane gate reads this table directly. One table, one reader, nothing to fall out
of sync.
